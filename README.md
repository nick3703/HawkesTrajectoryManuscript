# HawkesTrajectoryManuscript

R Code to conduct simulations and fit results from _Hawkes Trajectories: A Framework for Leadership Inference in Coordinated Movement_ by Clark and Mateu.

The file contains code to fit all results given in the manuscript. It requires the pigeon flight data available in the Dryad Digital Repository (Watts et al. 2016) at \url{https://doi.org/10.5061/dryad.508j2}
