# HawkesTrajectoryManuscript

R Code to conduct simulations and fit the Whale data from _Leadership Dynamic Inference From Hawkes-Inspired
Trajectory Models_ by Clark and Mateu.

The file ContinuousTimeSimulations.R replicates Section 6.1. The file DiscreteTimeMCSimulation.R replicates Section 6.2 and WhalesFit.R can be used (upon receipt of Whales data) to conduct the analysis in Section 7.
